# **Запуск теста для формирования отчета**
**Чтобы сформировать отчет по  тестированию необходимо в терминале выполнить команду pytest --alluredir allure-result из расположения проекта**
**Для просмотра сформированного отчета в терминале необходимо выполнить команду pytest allure serve allure-result**
